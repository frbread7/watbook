# Quantitative model scope and validation

All model-generated values are synthetic teaching values. They are not foundry measurements, product specifications, process recipes, fitted silicon data, or values taken from cited papers. No model is validated against a real wafer or production tester.

## Status vocabulary

- **Illustrative:** exposes a relationship or workflow with an explicitly simplified model.
- **Analytically checked:** representative outputs were independently evaluated from the stated equations and assumptions. This is not external or silicon validation.
- **Implementation-tested:** expected software behavior, input boundaries, and internal identities have tests. A deterministic repeatability or decomposition check against data generated by the same code is a self-consistency test, not an independent validation.
- **Numerically cross-checked:** an independent implementation or trusted numerical reference agrees within a declared tolerance.
- **Externally reference-checked:** a model result was checked against an appropriate public reference dataset or measurement. WATBook does not currently claim this status for any simulator.

No current simulator result is claimed as numerically cross-checked or externally reference-checked. Bibliographic checking confirms source identity and scope only; it does not validate model outputs.

## Model register

| Lab | Governing model and assumptions | Current check | Not established |
| --- | --- | --- | --- |
| Monitor-purpose planner | Set coverage: selected monitor IDs map to declared measurand labels. | Unit-tested on exact coverage and missing-measurand cases. | Structure quality, sensitivity, representativeness, monitor qualification, or process limits. |
| Threshold-extraction sensitivity | Long-channel, strong-inversion square-law saturation toy curve: `ID = Ioff + β(VGS − Vth)²`, with `β = μCoxW/(2L)` in A/V². The fitting points assume `VDS ≥ VGS − Vth`; VDS is not an input. Two explicitly added current offsets perturb a two-point square-root-line extrapolation. | The zero-noise constant-current and square-root results are checked against the closed-form equations; tests cover noise response, invalid criteria, negative Ioff, and finite numeric range. | BSIM or short-channel behavior, subthreshold/SS, DIBL, real extraction software, or a device limit. The model is not calibrated to silicon. |
| Standard-uncertainty budget | Independent standard components combined as `uc = sqrt(Σ ui²)`; expanded value `U = k uc`. Inputs share one unit. | The `3,4` components produce `uc = 5`; `k=2` produces `U=10`. Tests include negative, overflow, and invalid inputs. | Correlated components, nonlinear sensitivity coefficients, degrees-of-freedom assessment, or a guaranteed coverage probability. A value near k=2 is not automatically 95%; distribution and uncertainty-of-uncertainty assumptions matter. |
| Hierarchical wafer/lot map | Generated value = centered lot effect + centered wafer-within-lot effect + radial teaching term on a unit circular domain sampled by a square lattice; points outside the circle are omitted. The map has no die geometry, notch, or edge-exclusion rule. Measured value adds fixed channel offsets, linear test-order drift, and seeded bounded triangular random noise. The triangular noise has standard deviation `randomSigma`; it is not Gaussian. | Seed repeatability, generated-component sum identities, wafer IDs, circular mask, bounds, and invalid numeric/range inputs are implementation-tested. Components are analytically known because the data are generated by the same model; that is self-consistency, not physical validation. | Physical spatial law, actual instrument artifacts, process variance estimates, or a fit to wafer data. The arbitrary-unit offsets are chosen for visibility only. |
| WAT-to-EDS aggregation example | Four synthetic lots with paired observations. Within each lot, EDS changes by −2 arbitrary units per WAT unit; larger between-lot shifts make the pooled slope positive. EDS means electrical die sort (wafer sort). | For lot shifts `l ∈ {−1.5,−0.5,0.5,1.5}` and within-lot values `m ∈ {−4.5,…,4.5}`, `WAT=100+12l+m` and `EDS=500+30l−2m`. Their centered sums give pooled slope `433.5/188.25 ≈ 2.302789` and within-lot slope `−2`; tests assert both values. | A predictive relationship, causal effect, yield model, transferability, or a production disposition threshold. |
| Evidence-led diagnosis | Declared evidence directions in `{−1,0,+1}` are summed to create a transparent ordinal ranking. | Unit-tested for ordering, ties, and rejected invalid evidence weights. | Probabilities, calibrated likelihood ratios, causal inference, root cause, or an automatic disposition. |

The source and equation references are listed in [`REFERENCES.md`](REFERENCES.md) and linked near relevant chapter material. The TLM, control-chart, and general device-physics sources are related reading; WATBook does not implement a TLM or general SPC simulator.

## Reproducible checks

```sh
npm run test:models
```

The test code checks deterministic and analytically specified behavior. It does not replace device characterization, gauge studies, measurement-system qualification, or fab engineering review. See [`TECHNICAL_REVIEW.md`](TECHNICAL_REVIEW.md) for the review boundary and sign-off record.
