Each exercise is a small, deterministic model for reasoning about a specific measurement decision. Inputs include units; outputs include assumptions. These tools are not production test software, device simulators, process limits, or a disposition authority.

Model status: the arithmetic and edge cases are tested; the stated ideal equations are analytically checked where noted. No model is calibrated or externally validated against silicon or a production test flow. See model validation notes.
