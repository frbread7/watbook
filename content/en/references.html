Terms

WAT
Wafer acceptance test; wafer-level electrical measurements of defined monitor structures, with organization-specific scope.
PCM
Process control monitor or monitoring; a family of structures/measurements used to observe process responses.
EDS
Electrical die sort, also called wafer sort in many manufacturing flows; a product-die test stage distinct from monitor-structure WAT.
Measurand
The quantity intended to be measured, defined with enough context to distinguish it from similar quantities.
Type A / Type B
Uncertainty evaluation methods based respectively on statistical analysis of observations and other information, per metrology guidance.
Guard band
A decision-rule margin used to manage misclassification risk; not an instrument property.
Monitor structure
A dedicated test geometry whose electrical response is intended to inform a defined engineering question.
Coordinate transform
A documented mapping among coordinate frames, including units, origin, axes, orientation, and version.

Model validation status

  • Analytically checked (specified examples): independent-component RSS arithmetic; zero-noise square-law threshold outputs; the synthetic EDS example’s within-lot slope −2 and pooled slope 433.5/188.25 ≈ 2.303, from a separate closed-form calculation.
  • Implementation-tested: deterministic map generation, generated-component sum identities, and input boundaries. This checks software behavior and self-consistency, not the physical model or an independent numerical implementation.
  • Illustrative/unvalidated: monitor coverage bookkeeping, spatial + channel/order pattern, ordinal hypothesis scoring, and synthetic wafer-map realism.
  • External source check: bibliographic identifiers and the scope of cited public sources were checked. No model output is currently numerically cross-checked against an independent implementation or externally reference-checked against measured/public data.
  • Not performed: measured-silicon calibration, production equipment correlation, formal process qualification, or external laboratory certification.

All lab data are generated by local deterministic formulas. The wafer-map random component is bounded triangular noise with declared standard deviation, not Gaussian noise. Synthetic values are never represented as public production data.
