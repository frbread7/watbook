Distinguish raw responses from extracted parameters

A current-voltage trace is an observation under a particular stimulus, while a named parameter is a transformation of that observation. Extraction adds conventions: sweep direction, bias, current normalization, range, smoothing, fit interval, threshold definition, outlier handling, and software version. Two groups can measure the same transistor and report different “threshold voltages” without either instrument being broken if their definitions differ.

Store enough raw and derived data to reproduce the result. A defensible record includes sampled points or a trace reference, device and geometry identifiers, instrument/test-program revision, fit diagnostics, extraction method and revision, excluded points and reasons, and uncertainty or precision information. Preserve the distinction between direct observations and derived metrics in names and schemas.

Threshold voltage as an operational definition

Threshold voltage is not a uniquely observable discontinuity in a measured MOSFET curve. Common methods include constant-current criteria, linear extrapolation, transconductance-based methods, and methods adjusted for short-channel or series-resistance effects. The extracted result depends on drain bias, device geometry, normalization, temperature, current criterion, and the selected fitting region. Reviews of extraction methods discuss this method dependence; device physics and compact-model definitions are covered in the linked DeviceBook MOSFET chapter and Berkeley BSIM documentation.

For a deliberately restricted long-channel, strong-inversion saturation teaching model, define β = μCoxW/(2L) in A/V². It assumes VDS ≥ VGS − Vth for every fitted point and ideal square-law behavior:
ID = Ioff + β(VGS − Vth)², for VGS > Vth. Then a constant-current criterion Ic above Ioff gives
Vth,CC = Vth + √((Ic − Ioff)/β). The offset is part of this model’s definition, not an error that can be removed without context. A straight-line extrapolation of √(ID−Ioff) against gate voltage returns Vth for the noiseless square-law curve. Noise and a changed fit interval perturb it.

Interactive extraction sensitivity

The curve exercise computes these two outputs from a synthetic strong-inversion relation. Its default β is 1 mA/V², Vth is 0.45 V, and the constant-current criterion is 10 µA. With zero added noise, the equation gives 0.55 V for the constant-current result and 0.45 V for the square-root extrapolation. Changing the criterion or β moves the constant-current estimate; changing noise moves the fitted intercept.

This is a numerical illustration, not a transistor simulator. β includes the square-law factor 1/2 and represents a constant effective μCoxW/L; the widget does not compute VDS dependence. It omits subthreshold conduction, channel-length modulation, mobility degradation, drain-induced barrier lowering, source/drain resistance, body effect, self-heating, leakage mechanisms, and layout effects. It cannot estimate subthreshold swing (SS) because the model has no subthreshold regime. Never interpret its output as a technology or product limit.

Parameter families require separate contracts

Leakage, breakdown, transconductance, on-current, sheet resistance, capacitance, and contact-related values each depend on different structure and extraction choices. For example, a breakdown result needs polarity, ramp rate, compliance, and the definition of failure; an on-resistance needs the operating region, current, gate drive, temperature, and normalization. A capacitance result needs frequency, AC amplitude, bias sequence, equivalent-circuit choice, and open/short correction context.

Rather than treating a parameter name as a universal definition, maintain a versioned table that says what the value is, how it is computed, for which structure and range, and under what conditions it is valid. Changes to a recipe or extraction implementation should trigger a compatibility review before historical data are joined.

Knowledge check

Can a threshold trend be compared across two test programs if one changed drain bias and current normalization? Not without reprocessing compatible raw curves under a common definition or quantifying the effect of the change.
