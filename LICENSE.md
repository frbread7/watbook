# WATBook license and attribution

WATBook separates its original instructional content from its executable code, following the established My Library book-series convention.

| Material | License | Scope |
| --- | --- | --- |
| Original educational text, translations, questions, original diagrams/cover, and explicitly synthetic teaching datasets | [Creative Commons Attribution 4.0 International](LICENSE-CC-BY-4.0) | Chapters, figures, quizzes, documentation prose, and fictional data. Attribute WATBook and identify changes/translations when reusing. |
| Original executable code | [MIT](LICENSE-MIT) | JavaScript, CSS, Python tooling, tests, HTML structure, and simulator implementations. Preserve the copyright and license notices when redistributing copies or substantial portions. |

## Attribution and third-party material

WATBook's original explanations and artwork were authored for this repository. It links to independent engineering books as related reading; it does not copy their chapter text, code, or illustrations. Each reference source keeps its own rights and terms. A citation is not permission to reproduce protected tables, figures, or standards text.

The public standards sources linked in this book are bibliographic references, not incorporated standards. SEMI standards are not reproduced. No commercial instrument documentation is bundled. No third-party package or remote analytics service is required at runtime.
